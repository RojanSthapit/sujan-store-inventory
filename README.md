# Sujan Store — Inventory Manager (GitHub Pages)

Visual inventory manager synced with **Sujan Store List** Google Sheet (`Status` in Col L & `In Drive` in Col M) and Google Drive product photos.

## Setup (1 minute)
1. Open your **Sujan Store List** Google Sheet → **Extensions → Apps Script**.
2. Replace the editor contents with [`apps_script.gs`](./apps_script.gs) (optionally set `ACCESS_PIN`).
3. Click **Deploy → New deployment → Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. Copy the Web App URL, open the GitHub Pages site, click **⚙ Setup**, and paste the URL.
